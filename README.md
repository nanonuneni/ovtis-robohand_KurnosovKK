HomeWork

ОПИСАНИЕ
Скрипт поднимает web-server на localhost. Выводит текущий статус механической руки. Статус можно менять и он сохраняется в отдельный текстовый файл.

Запуск
Убедиться что установлен python3

УПРАВЛЕНИЕ
Посмотреть текущий статус: http://localhost:5000/

Установить статус в ON: http://localhost:5000/status-on

Установить статус в OFF: http://localhost:5000/status-off

В репозитории так же есть эскзиз робо-руки.
