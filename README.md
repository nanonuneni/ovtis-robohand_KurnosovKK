HomeWork

ОПИСАНИЕ
Скрипт поднимает web-server на localhost. Выводит текущий статус механической руки. Статус можно менять и он сохраняется в отдельный текстовый файл.

ИНСТРУКЦИЯ ПО ЗАПУСКУ СЕРВЕРА УПРАВЛЕНИЯ МЕХАНИЧЕСКОЙ РУКОЙ
1) Скачать файлы и распаковать их в одну папку
2) Открыть командную строку
3) Сменить директорию на путь до папки
4) Необходимо установить версию PHP 5.4 или новее.
5) Запустить команду php -S localhost:5000 (не закрывать командную строку)

СМЕНА СТАТУСА
1) Прописать команду curl "http://localhost:5000/?status=on" в командной строке.
2) В отдельной вкладке прописать http://localhost:5000/?status=on.
3) В файле status.txt изменить значение on/off.
